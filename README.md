# Over Hydration vs Minimal JS

This example demonstrates the concept of 'over-hydration' in web applications versus a 'minimal JavaScript' strategy. It contrasts a simulated scenario where a large JavaScript bundle is loaded to make an entire page interactive, with an approach where only targeted, minimal JavaScript is used for specific components, reducing overhead and improving performance.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
3. Open your browser's developer console (usually by pressing F12) to observe the JavaScript loading and execution logs for both approaches.
